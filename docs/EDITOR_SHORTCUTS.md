# Editor shortcuts

Generated by `engine_editor --dump-shortcuts docs/EDITOR_SHORTCUTS.md`; a test fails when this file is out of date.
Every key can be changed in Window > Keyboard Shortcuts. A shortcut works in its context, and Global ones work everywhere.
None fire while a dialog is open or a drag is in progress. While the game holds the mouse, only the ways out fire: Esc, F8 and Shift+F1.
While a text field has the keyboard, only Ctrl+P and Ctrl+Shift+P fire.

## Mouse

These cannot be changed yet.

| Input | Action |
|---|---|
| RMB drag | Look around |
| RMB + Wheel | Change camera speed |
| Shift while flying | Move three times as fast |
| LMB drag | Move forward and back, and turn |
| LMB + RMB drag | Move up, down and sideways |
| MMB drag | Pan |
| Wheel | Zoom |
| Alt + LMB drag | Orbit around the selection |
| Alt + RMB drag | Dolly |
| Alt + MMB drag | Pan |
| Click | Select |
| Ctrl + Click | Add to or take from the selection |
| Alt + drag a gizmo | Copy the selection and move the copies |
| Shift + drag a gizmo | The camera follows what moves |
| Hold V while dragging a gizmo | Snap to the nearest vertex |
| Esc while dragging a gizmo | Cancel the drag |
